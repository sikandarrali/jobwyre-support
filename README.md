This repo has no code — it's the single place to report bugs and request features for
[jobwyre](https://jobwyre.app), a job-application tracker. The app's source lives in a
private repo; this one exists purely so issues have somewhere public to live.

## 🐛 Reporting a bug

[**Open a bug report →**](https://github.com/sikandarrali/jobwyre-support/issues/new?template=bug_report.yml)

You'll get a short form to fill in — what happened, steps to reproduce, expected behavior,
and your device/browser. Screenshots help a lot for anything visual.

## ✨ Requesting a feature

[**Open a feature request →**](https://github.com/sikandarrali/jobwyre-support/issues/new?template=feature_request.yml)

The form asks for the problem you're running into before the solution — it's easier to
design around a problem than a specific ask.

## 🔎 Before opening a new issue

Please [search existing issues](https://github.com/sikandarrali/jobwyre-support/issues) first —
someone may have already reported it, and a 👍 on an existing issue is more useful than a
duplicate.

## 📬 Other contact

For anything that isn't a bug or feature request — account/billing questions, security
reports, or general feedback — use the contact form in the app at
[jobwyre.app](https://jobwyre.app).
